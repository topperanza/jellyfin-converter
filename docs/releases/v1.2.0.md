# Jellyfin Converter v1.2.0 Release Notes

## Overview
This release advances GA rollout readiness by formalizing release operations and installer integrity gates while preserving the v1 CLI contract.

## Highlights
- Contract and compatibility docs are now explicit and versioned.
- Release packaging includes checksummed assets and installer verification.
- CI and release workflows enforce blocking gates for docs/version sync, action pinning, packaging, and installer validation.
- Operational runbooks now cover incident handling, recovery, and troubleshooting.

## Upgrade Notes
- No breaking CLI changes.
- Installer remains the public install entrypoint (`install.sh`).

## Known Issues
- Hardware acceleration availability depends on host GPU drivers/ffmpeg build.
